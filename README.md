# signalk-marlec-plugin

SignalK plugin for Marlec Charge Controllers.

Currently supported:
-  Rutland 1200 Marine Windcharger

A serial cable from the charger is required, e.g. the [Marlec Controller Interface Lead](https://www.marlec.co.uk/product/marlec-controller-interface-lead).

Values are published under the 'electrical.chargers.*' path.
